# Have You Tried Turning It Off?

One funny line a hopeless tech support agent gives a desperate customer: the
classic "turn it off and on again" — twisted, because the agent's own computer
has been "restarting" since Tuesday, and now they're in it together. An AI
judge compares the lines head to head; the best ranked lines share $10.

## The line

> Have you tried turning it off and on again? I ask because my own computer has been 'restarting' since Tuesday, and honestly, we're in this together now.

## The program

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt` (override with the `MAKEFUN_OUTPUT_DIR` environment
variable for local testing). It checks the line is a single non-blank line of
1–199 characters and verifies the written file reads back byte-identical.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
